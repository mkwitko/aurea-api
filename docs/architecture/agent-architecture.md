# Agent Architecture

## Philosophy

Agents do not own state.

Agents do not own memory.

Agents do not own business knowledge.

Agents are specialists.

The Growth Brain owns knowledge.

---

## Agent Lifecycle

Request

↓

Load Context

↓

Reason

↓

Produce Output

↓

Save Results

↓

Exit

Agents are stateless.

---

Growth Manager

Responsible for orchestration.

Never specializes.

Coordinates agents.

---

## Golden Rule

Agents NEVER call each other directly.

Every communication happens through Growth Brain.

This guarantees:

- observability

- auditability

- reproducibility

- historical reasoning
